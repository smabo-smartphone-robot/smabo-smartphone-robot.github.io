## Overview

This page explains the **Face feature** of smabo.

Specifically, you will:

- Change smabo's expressions via smabo-web

    <video autoplay loop muted playsinline style="max-width:100%"><source src="/video/eye_change.mp4" type="video/mp4"></video>

- Control smabo's eyes via smabo-web

## Operation

### Startup Procedure

Follow <a href="/en/guides/startup/" data-steps="smabo-brainの起動,smabo-webの起動,smabo-brain---smabo-webの接続,smabo-appの接続">the startup procedure here</a>.

### Changing Expressions

In smabo-web, open the **Face Settings**.

![Face Settings button in smabo-app](/images/app_face_settings_button.png)

Select an expression from the list to change smabo's face.

![Selecting an expression in smabo-web Face Settings](/images/app_expression_set.jpg)

### Eye Control

The **Eye Controller** lets you manually move smabo's eyes.

![Moving smabo's eyes with the Eye Controller in smabo-web](/images/app_gaze_control.jpg)

Drag anywhere on the controller to point smabo's eyes in that direction.

<video autoplay loop muted playsinline style="max-width:100%"><source src="/video/eye_control_manual.mp4" type="video/mp4"></video>

#### Follow Mode

Enable **Follow mode** to make smabo's eyes follow your finger.

![Setting the smabo-app face mode to Follow](/images/app_eye_follow_mode.png)

### Face Settings

In **Face Settings**, you can customize each facial expression (colors, shapes, animation speed, etc.).

![smabo-app face settings: eye type, background color and more](/images/app_face_settings.png)
